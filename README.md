# C.R.E.P — Cool Reverse Engineering Program

A free and open-source reverse engineering tool built from scratch in C++ (Win32).

## Building

Requirements:
- Visual Studio 2022 (v143 toolset)
- Windows 10 SDK

Open `crep.sln` in Visual Studio and build (F7).

## Roadmap

- [ ] PE file loader (headers, sections, imports/exports)
- [ ] ELF file loader
- [ ] Hex viewer with editing
- [ ] x86/x64 disassembler
- [ ] ARM/AArch64 disassembler
- [ ] Control flow graph (CFG) visualization
- [ ] Decompiler (C-like pseudocode output)
- [ ] Cross-references (xrefs)
- [ ] Symbol and string analysis
- [ ] Signature scanning / pattern matching
- [ ] Scripting / plugin API
- [ ] Struct and type editor
- [ ] Debugger integration
- [ ] Diffing (binary comparison)
- [ ] Dark theme UI
